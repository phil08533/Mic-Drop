# Mic-Drop
Mic Drop game made in Godot.

Homepage 
|_ Add Team
|     |_ Add Player
|_ Start Game
      |_ Randomize two teams who go first
      |_ Selects cards for each team player
      |_ Allows for selection of music style
      |_ Plays a random song from the style 
      |_ Wait until complete button is pressed
      |_ Team 3 decides winner and asigns score 
      |_ Meter fills up for that team
                  |_ if meter fills they are winner
